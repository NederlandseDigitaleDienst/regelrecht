This number is held for
[pull request 1997](https://github.com/NederlandseDigitaleDienst/regelrecht/pull/1997),
which proposes an RFC on rules that hold in a place: a law gives an area as a
shape, and the location of a case decides which decentralized regulation fills
an open term.

See [RFC-000](/rfcs/rfc-000) for why a number is claimed on the default branch
when the pull request opens, rather than when it merges.
